# Security Policy

## Supported versions

MengXia is pre-release software. Security fixes are made on the current `main`
branch; no released version currently carries a long-term support commitment.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/XiaTian-X/MengXia/security/advisories/new)
for suspected vulnerabilities, credential exposure, privilege-boundary failures or
unsafe filesystem/network behavior.

Do not open a public issue, discussion or pull request containing exploit details,
private data, credentials or reproduction artifacts that could harm users. Include
the affected commit, preconditions, impact and a minimal safe reproduction where
possible. No response-time or bounty commitment is made during the pre-release phase.
